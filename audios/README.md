# Audios Directory

This directory contains audio assets for the One-Armed Band game.

## Expected Files:
- `drums.mp3` - Drum track
- `trumpet.mp3` - Trumpet track
- `bass.mp3` - Bass track
- `violin.mp3` - Violin track
- `piano.mp3` - Piano track
- `flute.mp3` - Flute track
- `guitar.mp3` - Guitar track

## Group-Specific Audio (Optional):
- `drums_A.mp3` - Specific drum track for Group A
- `trumpet_B.mp3` - Specific trumpet track for Group B
- `bass_C.mp3` - Specific bass track for Group C

## Supported Formats:
- MP3 (recommended)
- WAV
- OGG
- M4A

## Fallback Behavior:
If audio files are not found, the game will use silent audio tracks as fallbacks.

## Audio Requirements:
- Should be loopable
- Length: 30-60 seconds recommended
- Sample rate: 22050 Hz
- Format: Stereo
- Volume: Normalized to prevent clipping
