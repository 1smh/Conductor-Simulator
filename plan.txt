# One-Armed Band Game - Updated Implementation Plan

## Game Overview
A conductor game where you synchronize musicians in an orchestra. Different groups play different instruments, and you must tap space to keep them synchronized while removing bad actors with Q.

## Detailed Function and Variable Documentation

## Game Balance:
- Beat alignment factor: 0.3 (30% improvement from conductor intervention)
- Offsetness threshold: 5.0 (maximum allowed sync deviation)
- Minimum musicians per group: 1 (to continue playing)
- Bad actor probability: 1% per frame
- Game duration: 60 seconds (configurable)

## Controls:
- **Space**: Synchronize the orchestra (reduce offsetness)
- **Q**: Remove bad musicians (click on red pulsing musicians)
- **Arrow Keys/WASD**: Move conductor (limited range)
- **Escape**: Pause game
- **R**: Restart from victory/defeat screen
