# Images Directory

This directory contains image assets for the One-Armed Band game.

## Expected Files:
- `conductor.png` - Conductor character image
- `stage.png` - Stage texture
- `background.png` - Background image
- `musician_A.png` - Musician image for Group A
- `musician_B.png` - Musician image for Group B
- `musician_C.png` - Musician image for Group C

## Fallback Behavior:
If images are not found, the game will use colored cubes as fallbacks:
- Conductor: Gold cube
- Musicians: Colored cubes based on group (blue, green, orange)
- Stage: Brown cube
- Background: Dark gray cube

## Supported Formats:
- PNG (recommended)
- JPG/JPEG
- BMP
- TGA
